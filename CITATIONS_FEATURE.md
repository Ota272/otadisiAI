# Функционал цитирования из PDF документов

## Что реализовано

### 1. Генерация цитат в Gemini (ml/shap_integration.py)

Функция `generate_gemini_expert_opinion()` теперь:
- Возвращает JSON с полями `conclusion` и `citations`
- В `conclusion` встроены маркеры `[CITATION:N]` для каждого пункта
- В `citations` массив объектов:
  ```json
  {
    "point_number": 1,
    "quote": "точная цитата из PDF",
    "line_number": 42,
    "explanation": "почему это важно"
  }
  ```

### 2. Нумерация строк PDF

Текст из PDF теперь передаётся в Gemini с номерами строк:
```
[   1] Договор купли-продажи №45/2026
[   2] Продавец: ТОО «Племзавод Алматинский»
[   3] Покупатель: ТОО «Агро-Элита», БИН 123456789012
...
```

Это позволяет Gemini точно указывать откуда взята цитата.

### 3. Отображение на фронтенде (frontend/frontend.py)

#### CSS стили добавлены:
- `.citation-icon` - круглая иконка скрепки (22x22px)
- `.citation-popup` - всплывающее окно с цитатой
- `.citation-quote` - блок с текстом цитаты
- `.citation-line-number` - номер строки в документе
- `.citation-explanation` - пояснение важности

#### Логика рендеринга:
1. Парсит JSON ответ от Gemini
2. Извлекает `conclusion` и `citations`
3. Заменяет маркеры `[CITATION:N]` на HTML иконки
4. При наведении на иконку показывается popup с:
   - Точной цитатой из PDF
   - Номером строки в документе
   - Пояснением почему это важно

### 4. Промпт для Gemini

Обновлён system_prompt:
- Требует JSON формат ответа
- Для каждого из 5-8 пунктов заключения нужна цитата
- Указывать точный номер строки из нумерованного текста PDF
- Максимум 3 цитаты на один пункт

## Как это работает

### Поток данных:

1. **Загрузка PDF** → извлечение текста → текст с номерами строк
2. **Gemini анализ** → генерация JSON с conclusion + citations
3. **Фронтенд** → парсинг JSON → замена маркеров на иконки
4. **Пользователь** → наводит на скрепку → видит цитату из PDF

## Известные ограничения

1. **PDF без текста** (сканы без OCR) - цитаты не будут сгенерированы
2. **Лимит токенов** - очень большие PDF могут быть обрезаны
3. **Точность номеров строк** - зависит от качества извлечения текста
