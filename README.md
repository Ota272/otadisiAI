# otadisiAI
AI-Интеллектуальное ядро скоринга (Scoring Engine) для Министерства сельского хозяйства РК. Система переводит распределение госсубсидий с устаревшей модели «кто первый подал» на справедливый merit-based подход, ранжируя фермеров по экономической эффективности. Включает полную объяснимость ИИ и оставляет финальное решение за человеком.
