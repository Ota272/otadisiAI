**Хакатон Decentrathon 5.0 | AI for Government**

---

## 📖 О проекте

**SmartAgro Score** — информационно-аналитическая система для автоматизированного скоринга заявок на субсидии в сельском хозяйстве.

Система оценивает каждое предприятие по 8 ключевым показателям и выдаёт:
- **Скоринговый балл (0–100)** — вероятность одобрения заявки
- **Категорию**: 🟢 green (рекомендовано) | 🟡 yellow (на рассмотрении) | 🔴 red (риск)
- **SHAP-объяснения** — какие факторы повлияли на решение

🏗 Архитектура
Ввод данных (Data Ingestion): Сотрудник Минсельхоза вручную загружает данные по заявкам фермеров через удобный интерфейс. Система поддерживает мультиформатную загрузку (CSV, Excel, JSON и другие табличные или текстовые форматы).
Backend-процессинг (FastAPI): Обрабатывает загруженные файлы, нормализует данные и передает их в ML-пайплайн.
Scoring Engine (CatBoost): Анализирует 8 ключевых признаков заявки и рассчитывает вероятность успешного исполнения обязательств.
Explainable AI (SHAP): Генерирует интерпретируемые объяснения (положительные и отрицательные факторы), чтобы избежать принципа "черного ящика"
.
Frontend (Streamlit): Визуализирует шорт-лист кандидатов и подробные дашборды с графиками для каждого заявителя. Система строго соблюдает принцип Human-in-the-loop — финальное решение (одобрить/отказать) принимает человек
.
