Авторизация

Все запросы требуют API ключ в заголовке X-API-Key.

Важно: Не передавайте ключ в URL или теле запроса.

Пример

curl -X GET http://localhost:8003/api/v1/applications \
-H "X-API-Key: sk-msgov-2025-demo-key-abc123"
import requests
r = requests.get("http://localhost:8003/api/v1/applications", headers={"X-API-Key": "sk-msgov-2025-demo-key-abc123"})
const r = await fetch('http://localhost:8003/api/v1/applications', {headers: {'X-API-Key': 'sk-msgov-2025-demo-key-abc123'}});

Расчёт скорингового балла (0–100).

Параметры

ПараметрОписание
bin_iin reqБИН/ИИН (12 цифр)
company_name reqНаименование
region reqОбласть РК
subsidy_type reqТип субсидии

pedigree_ratioДоля племенного (0.5)

-H "Content-Type: application/json" \

POST/api/v1/decision

Решение комиссии (Human-in-the-Loop).

Параметры

ПараметрОписание
application_id reqID заявки
decision reqapproved/rejected/review
commentКомментарий

Пример

curl -X POST http://localhost:8003/api/v1/decision \
-H "Content-Type: application/json" \
-H "X-API-Key: sk-msgov-2025-demo-key-abc123" \
-d '{"application_id":"A7F2B1C0","decision":"approved","comment":"Соответствует критериям, рекомендовано к одобрению"}'
Data loop: после успешного POST заявка получает is_verified=1 в БД; решение пишется в verified_payload.commission_decision.
POST/api/v1/applications/{application_id}/expert-verify

Явная проверка экспертом: is_verified=1, произвольный JSON правок в verified_payload.

curl -X POST http://localhost:8003/api/v1/applications/A7F2B1C0/expert-verify \
-H "Content-Type: application/json" \
-H "X-API-Key: sk-msgov-2025-demo-key-abc123" \
-d '{"comment":"ОК","verified_payload":{"corrected_zone":"yellow","note":"ручная правка"}}'
GET/api/v1/training-samples

Все заявки с is_verified=1 (для XGBoost). Query: ?zone=red — только красная зона.

curl "http://localhost:8003/api/v1/training-samples?zone=red" \
-H "X-API-Key: sk-msgov-2025-demo-key-abc123"
SQLite: файл data/applications.sqlite в корне проекта — можно открыть в DB Browser for SQLite и выполнить SELECT * FROM applications WHERE score_zone = 'red';
